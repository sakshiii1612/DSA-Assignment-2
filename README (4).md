Data Structures and Algorithms – Assignment 2 in C

This repository contains C language programs based on various Data Structures and Algorithms concepts, including Arrays, Stack, Queue, Searching and other operations. These programs are completed as part of academic coursework.

📌 Programs & Implementations

1. Array Operations

- "insert-array.c" – Insert an element at a specific position in an array.
- "delete-array.c" – Delete an element from a specific position in an array.
- "reverse-array.c" – Reverse the elements of an array.
- "nextgreater-array.c" – Find the next greater element in an array.

2. Searching Algorithms

- "linearsearch-array.c" – Implement Linear Search.
- "binarysearch-array.c" – Implement Binary Search.

3. Stack Operations

- "stack-array.c" – Implement Stack using an array.
- "push and pop-linkedlist.c" – Implement Push and Pop operations using a Linked List.
- "reversestring-stack.c" – Reverse a string using Stack.

4. Queue Operations

- "enqueue and dequeue-array.c" – Implement Enqueue and Dequeue operations using an array.
- "queue-linkedlist.c" – Implement Queue using a Linked List.

🛠️ Technologies Used

▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in VS Code.
4. Compile the C program using GCC:

gcc filename.c -o filename.exe

5. Run the executable:

.\filename.exe

Example:

gcc insert-array.c -o insert-array.exe
.\insert-array.exe

Note: Replace "filename.c" with the name of the program you want to execute. Run each C file separately.
